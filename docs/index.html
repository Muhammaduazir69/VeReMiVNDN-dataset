Get the data

The data ships as GitHub release assets rather than as files in the repository, because git handles a few GB of compressed CSV badly.

curl -LO https://github.com/Muhammaduazir69/VeReMiVNDN-dataset/releases/download/v1.0.0/veremivndn_ml.tar.gz
tar xzf veremivndn_ml.tar.gz
sha256sum -c CHECKSUMS.sha256

Each file is a gzipped CSV with a header, so pandas reads it directly.

import glob, pandas as pd

df = pd.concat([pd.read_csv(f) for f in glob.glob("data/ml/*.csv.gz")],
               ignore_index=True)
print(df.attack.value_counts())

The label schema

This is the question that comes up most, so it is worth stating plainly.

ColumnMeaning
attack The attack configured for the run. Constant within a run.
attackType Ground truth for the row. What the recording node was doing at that instant, or Benign.
isAttack 1 when attackType is not Benign. The binary target.
Do not train on attack. It describes the run, not the row. A malicious vehicle is benign before its attack window opens at t = 60 s and again after it closes at t = 240 s, and every benign vehicle in an attack run is benign throughout. Using attack as the target labels most of an attack run as malicious and produces scores that look far better than they are.

The four attacks

ConfigurationAttackMechanism
Attack01_InterestFloodingInterest Flooding Interests for names that cannot be satisfied, so PIT entries pile up and expire.
Attack05_NamePrefixHijackingName Prefix Hijacking Advertises prefixes it does not serve, pulling Interests from real producers.
Attack12_InterestAggregationInterest Aggregation Abuses PIT aggregation so one Interest suppresses forwarding of others.
Attack18_RoutingInfoFloodRouting Info Flood Floods routing updates to destabilize the FIB.
BenignTrafficNoneAttacker-free control.

The simulator implements more attacks than these across other planes. They are not part of this dataset and were not run.

The grid

225 runs of 300 simulated seconds: 5 configurations × 3 densities × 3 attacker ratios × 5 seeds.

AxisLevels
Densitylow 77 vehicles, med 151, high 356
Attacker ratio5 %, 10 %, 20 % of the fleet

Before you draw conclusions

This release was regenerated after publication. Five defects in the export path were repaired first. Two were severe enough that the original pipeline could not have produced a usable dataset: the routine that fills the feature window had no caller anywhere in the source, so all 69 features held their default values, and no attack module ever reported itself, so every row was labeled benign whatever the configuration. Numbers computed from this release will not match the published tables. The release is the version to trust.

All runs use one road network and one vehicle class, attackers hold a fixed rate and strategy for their whole window, and four of the ten heuristic score columns are unimplemented stubs that return a constant. The data dictionary and instructions cover all of this.
